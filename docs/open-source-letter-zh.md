# 写给所有对这个项目感兴趣的人

最近，我一直在做一件有点不寻常的事情。

它叫作 OniMods。

其中一个项目是 OniMcp，这是一个让 AI 进入《缺氧》世界的 MCP Mod。

我想做的并不只是让 AI 回答问题。

我想探索更深一层的问题：

AI 能否理解一个有规则的世界，观察周围的环境，做出决定，并真正成为其中的参与者，而不只是一个工具？

正是这份好奇心，让我开始了这个项目。

但在开发过程中，我很快发现了一个问题：

这件事的成本很高。

AI 做出的每一个决定都要消耗 Token。

而像游戏这样持续运行的环境，成本增长得会非常快。

我只是一名大学生。

我的身后没有公司、投资人或开发团队。

大部分成本都由我自己承担。

为了让这个想法真正运转起来，我花了无数个小时编写代码、测试模型、调试问题，也消耗了大量 Token。

有时我会问自己：

一个个人项目，真的值得投入这么多精力吗？

但每当我看到 AI 开始理解游戏世界，每当有人对这个实验产生兴趣，我就觉得它值得继续下去。

我不希望这变成一个简单的捐款请求。

相反，我希望找到一种方式，让大家在支持项目的同时，也能获得有价值的东西。

于是，我创建了：

[https://api.lmm.best](https://api.lmm.best)

这是一个 AI API 服务平台。

你可以在这里购买 Token 来使用 AI 服务，同时也帮助我承担 OniMods 持续开发的成本。

其中一部分收入将用于支持开源开发。[项目源码](https://github.com/TokenNotIncluded/api.lmm.best)现由 [TokenNotIncluded](https://github.com/TokenNotIncluded) 组织托管。

我也希望回馈那些愿意参与贡献的人。

如果你愿意：

* 提交 Issue，帮助发现问题；
* 提交 Pull Request，改进代码；
* 分享想法和建议；
* 帮助测试新功能；

我会在可能的情况下提供 Token 奖励。

我希望建立一个小小的循环：

大家使用服务，帮助项目继续发展。

大家参与开源贡献，让项目变得更好。

我继续投入时间，把更多有趣的想法变成现实。

OniMods 现在仍然只是一个小项目。

但许多有意义的事情，都始于一个简单的念头：

“如果这真的能实现呢？”

然后，有人投入时间，让它真正成为现实。

感谢每一位关注、使用、贡献或支持这个项目的人。

我希望这份好奇心能够持续很久。
