# CycleTrim：不足两倍场景的专项优化计划

日期：2026-10-31（Asia/Taipei）。本文件在本轮候选计时之前提交。

## 本质与目标

这些补丁是在原循环周围增加比较或查表，只有省掉的工作超过新判断的成本才会变快。本轮对上轮不足两倍的每个组合分别检查这种成本关系，优化能够合法省去的调用、比较和临时对象。

大纲：目标清单；三个专项机制；固定测量协议；正确性验证；交付与复核。

## 固定目标清单

[机器可读清单](target-matrix.json)来自已提交的整合测量：6 个轨道、13 个动画、2 个电力组合，共 21 个目标。重复 256 符号的 setter 在上轮为 2.126 倍，作为保留对照继续测量。所有 22 个组合都会复测。

上轮表中的增量对照起点是 `6206791`。本轮保留它作为累计两倍目标的起点，并另列当前版本 `09c496c` 的增量和未打补丁的原始夹具对照。旧报告中位数只用于选定目标，不用于相乘推导本轮加速比。

## 专项机制与动机

1. 轨道：检查三个成员查找中的闭包调用和重复寻址；对能够证明只有整数相等比较的谓词，研究直接扫描，并保持原删除、方向回调、嵌套失效和异常顺序。兼容检查需要看到后安装的补丁。
2. 动画：将能够证明安全的六字段写入块合并比较；第一次发现变化后进入原方法后续循环，减少后续符号上的比较和状态判断。复杂地址或可能改变部分写入行为的形状继续走已验证路径。
3. 电力：保留单张有界字典，复用管理器身份哈希，减少依赖补丁检查中的遍历分配；所有电路路由、回调次数、作用域和弱生命周期约束保留。

每项候选先通过正确性验证，再执行小规模诊断；不采纳的候选保留源码差异和测量。两倍是需要测量判断的目标，不作为删减必要工作或选择样本的理由。

## 固定测量协议

最终比较三个版本：累计起点 `62067913a5aea4daa4a8991689c86aad261b1269`、本轮起点 `09c496c46b4879cbdce4a8a9056b3f85f9c5c0d3`、经完整验证的最终候选。使用相同已有 Benchmark 实现、输入、预热和迭代次数；源文件哈希核对基准未变。

正式比较每个组合七组相邻的三个进程，每组同时包含三版。六种排列依次轮换，第七组回到第一种，预先固定顺序。每个进程保留原始／补丁的交替样本顺序，CPU 固定为 0，两版基准及候选统一设 `DOTNET_TieredCompilation=0`。计时期间不构建或运行其他测试；共享宿主不视为独占硬件。

逐组计算累计起点／候选、本轮起点／候选和原始／候选的耗时比，分别报告最小值、中位数、最大值、改善组数及是否达到两倍。保存全部原始记录，不剔除离群值。输出、方向读取、电力查询、动画复制次数和复制字节必须一致；缺失、重复或不匹配的记录使汇总失败。

另运行三版的原有完整 CLI 基准，使用默认运行时；与正式三版交错结果分开报告。已有存档元数据基准此前约 5.465 倍，作为独立回归控制复核，不与这 21 个目标混合。

## 正确性与交付

保留并扩展真实 Harmony 宿主回归、设置／探针测试、net48 参考构建和完整 PR 差异检查；最终提交需要对应 SHA 的 GitHub CI。新增直接读取或循环改写必须覆盖精确位模式、别名、异常后的部分写入、嵌套恢复、后安装补丁和适用形状回退。

按可复核的阶段及时推送 GitHub，最后将报告及允许公开的源码差异、原始样本副本上传到 Google Drive 的 OniMods 目录。游戏 DLL、反编译实现源码、私人存档和凭据不进入交付包。Steam／Unity／Mono 真实存档验收单独记录。
