OniOnline 0.5.0：联机框架开发预览

和朋友进入同一个大厅聊天。默认不登记星球，也不搬迁殖民地。

OniOnline 是联机玩法的开发框架。内置玩法只有聊天。一人一星球或其他玩法做成单独的模组，注册后即可使用同一套大厅、会话和状态频道。它不会自动同步任意模组的内部数据或整个游戏模拟。

入口：
• 主菜单“浏览大厅”用于查找、加入和创建房间。
• 进入殖民地后，从原生管理栏气泡直接打开通讯；默认 Ctrl+T。
• 声明 onionline.worlds.v1 的玩法模组才会打开星球登记和星图。

提供 Steam 公开大厅、局域网发现、大厅码、聊天、连接恢复和主人管理。声明世界能力的玩法才开放授权观察；远程施工和复制人操作关闭。完整殖民地迁移、火箭互访、物资运输和离线托管尚未实现。

加入玩法前先对齐必需模组的来源、版本、内容摘要和实际加载状态。公开工坊内容可经确认下载；下载完成仍需原生游戏安装、在模组菜单启用并重启，再重新加入。Local/Dev 模组不自动分发。运行中同步只覆盖模组通过 SDK 注册并授权的状态频道。

CycleTrim 和 Spaced Out! 不是固定前置。基础会话按协议、玩法和功能能力协商，不要求游戏构建号或 DLC 标签简单相等。当前原生适配器登记构建 744825：本体支持星球身份和观察采样，Spaced Out! 另支持原生星图。未知构建的原生功能不可用，不承诺任意游戏版本兼容。星系主人启用的其他必需模组仍须按清单对齐。

当前源码候选为 0.5.0、协议 11，仍处于开发预览；这份文案不表示已发布到 Steam。新版界面的图形交互、实际工坊下载与原生重启、两个真实游戏客户端的联机仍待完整验收。局部宿主测试不能代替实机结果，请使用存档副本参与测试。
