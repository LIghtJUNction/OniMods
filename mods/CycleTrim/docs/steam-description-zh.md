[h1]CycleTrim[/h1]

[b]拯救大后期卡顿！《缺氧》极致轻量性能优化 Mod[/b]

玩到几百甚至上千周期，游戏越来越卡、每天清晨存盘卡半天？
[b]CycleTrim[/b] 针对《缺氧》底层的核心模拟瓶颈进行外科手术级剪枝，彻底消灭无效算力开销，显著提升帧率并减少卡顿，同时[b]100% 保持原版原汁原味的游戏逻辑[/b]。

[h2]⚠️【必需前置 Mod】[/h2]
本模组接入统一前置库 [b]Jlib[/b]（创意工坊 ID: [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3835083839]3835083839[/url]）。
[b]请先订阅 Jlib，并在游戏模组列表中将其排列在 CycleTrim 之前启用。[/b]

[h2]⚡ 核心优化亮点[/h2]
[list]
[*] 🏃 [b]忙碌复制人待办节流[/b]：当小人正在进行科研、深度挖掘或操作机床等不可打断的长任务时，智能挂起每帧对其重复扫描全图待办的开销，最高削减 50%+ 脑力计算损耗！
[*] 🐾 [b]圈养动物寻路剪枝[/b]：牧场里静止发呆的小动物不再高频触发全图寻路（NavGrid）探针，大幅减轻导航计算压力，动物密集区帧率提升高达 30%+。
[*] 📦 [b]地面碎片拾取加速[/b]：随着基地物资累积，地面散落上万碎片时，优化空间筛选与路径代价复用，大幅减少“寻找可用物资”造成的瞬间掉帧。
[*] 💾 [b]闪电级存档元数据优化[/b]：优化每日清晨存盘时的组件反射查询，实测单次保存元数据处理提速 1.5×~2×，告别天亮卡死。
[*] 🦀 [b]内置 OniSim 原生仿真核心[/b]：预置由 Rust 编写的高性能流体与网格计算组件（支持 Windows / Linux / macOS），利用现代 CPU 指令集大幅加速原生运算。
[/list]

[h2]🛡️ 安全与兼容性承诺[/h2]
[list]
[*] [b]原汁原味[/b]：绝不修改复制人优先级、日程、属性、移动速度或游戏平衡性数值。
[*] [b]生态共存[/b]：深度适配官方本体与《眼冒金星》(Spaced Out!) DLC；主动检测 FastTrack、Plib 等流行 Mod，遇冲突自动安全降级，绝不报错炸档。
[*] [b]零堆分配防顿卡[/b]：热路径经过极致内存优化，杜绝高频垃圾回收（GC）造成的微小卡顿。
[/list]

[h2]⚙️ 可配置选项[/h2]
