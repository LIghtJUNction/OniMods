# 太空开发与火箭技术专题指南

突破地表、征服太空是《缺氧》中后期迈向无限资源、稀有物质（富勒烯/超冷剂、异构树脂/绝热材料、铌、超导）的终极篇章。

---

## 1. 地表环境与流星防护工程

* **真空辐射与气体散失**：
  * 太空边缘（Space Exposure）为暴露真空，任何未密封的气体都会瞬间流失逃逸至太空（无法找回）。
  * 地表建筑必须使用**干板墙（Drywall）**作为背景阻断气体泄漏，并用隔热气密门进出。
* **流星雨（Meteor Showers）防御**：
  * 流星携带极高动能与灼热高温，能瞬间摧毁普通砖块和建筑。
  * **防御三件套**：
    1. **地表雷达站（Space Scanner）**：网络质量达到 100% 可提前数十秒检测到流星警报，发出绿灯信号。
    2. **地堡门（Bunker Door）**：雷达报警时自动化闭合防空，抵挡流星直接砸击。
    3. **自动采掘机（Robo-Miner）防埋**：流星撞击后会留下极厚的表土（Regolith）。必须在掩体下方安装采掘机自动挖掘表土，防止门机卡死。注意：采掘机在真空中无法散热，需滴微量液体（几十克原油）导热。

## 2. 太阳能电池阵列（Solar Power）

* **无限免费能源**：
  * 太阳能电池板（Solar Panel）在阳光充足时每块产出高达 **380W** 清洁电能。
* **梯形错落布局**：
  * 太阳能板光线穿透率为 80%，采用“阶梯式”前后重叠排列，可以在有限地表宽度内捕获最大太阳光通量。
  * 产生的电力直接通过高压线接入全基地主干电网，白天作为基底主力供电，节约地下发电机燃料。

## 3. 火箭推进阶梯（Rocketry Ladder）

在《眼冒金星》（Spaced Out!）DLC 与本体中，火箭遵循严密的分级演化体系：

1. **第一阶：二氧化碳火箭（Carbon Dioxide Rocket）**：
   * 燃料来源极简，直接收集基地排放的废弃二氧化碳。
   * **使命**：开辟首个卫星轨道探测、投放轨道货舱、短距离考察邻近小行星。
2. **第二阶：糖动力 / 蒸汽火箭（Sugar / Steam Engine）**：
   * 蔗糖（Sucrose）或 95℃ 以上水蒸气驱动。
   * 负载能力提升，建立首个外星前哨基地，开采铝、硫、树脂等稀缺材料。
3. **第三阶：石油火箭（Petroleum Engine）**：
   * 消耗精炼石油与液氧（Liquid Oxygen），航程跨越 10~16 格星系区块。
   * 具备强大的多货舱运输能力，支持规模化星际矿产采运。
4. **终极阶：氢氧火箭（Liquid Hydrogen Engine）**：
   * 消耗 **-252℃ 液氢** 与 **-183℃ 液氧**。
   * 动力比冲最高，直达宇宙最边缘星体，获取**富勒烯（用于超冷剂）**、**异构树脂（用于绝热砖）**与**质子石**。

## 4. 太空生活舱（Spacefarer Module）内部环境构建

* **微型闭环生活区**：
  * 在狭小的舱内集成：水冲马桶（带自循环水净化器）、墙壁挂床、脱水食品机（Dehydrated Food）、氧气扩散罐与小型娱乐设备。
  * 舱壁铺设地毯砖（+装饰度），让宇航员在数百周期的长途星际旅程中士气稳定在 30+，零压力安全返航。
