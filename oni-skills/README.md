# oni-skills：缺氧策略与工程知识库

OniMods 的可选子项目，供玩家和 Agent 查询开局、制氧、养殖、温控、喷孔、电网与太空方案。核心 Mod 不依赖本目录即可编译运行。

[独立仓库入口](https://github.com/LIghtJUNction/oni-skills)；当前检出由 OniMods 主仓库跟踪。本目录修改不代表独立仓库已同步。

## 从哪里开始

- Agent 从 [SKILL.md](SKILL.md) 按问题选择攻略。
- 玩家可先看 [核心心法](guides/veteran-rules.md) 和 [开局与基地](guides/opening-and-base.md)。
- 堵管、循环、过滤和物流问题看 [管道与运输排障](guides/pipes-and-transport.md)。
- 模块专题：[制氧与水](guides/oxygen-and-water.md)、[食品与养殖](guides/food-and-ranching.md)、[工业与热控](guides/heat-and-industry.md)、[喷孔驯化](guides/geysers-and-taming.md)、[电网与自动化](guides/automation-and-power.md)、[太空与火箭](guides/space-and-rocketry.md)。
- 查证范围、具体来源和版本差异见 [SOURCES.md](SOURCES.md)；补充资料请看 [贡献指南](CONTRIBUTING.md)。

## 怎么使用这些建议

先确认本体还是《眼冒金星》、构建号、内容包与 Mod。机制数据用来计算，模块建议用来选型，真正建造仍需要完整图纸和现场检查。

本轮于 2026-10-23 对照大叔追云彩语雀正文、Wiki 检索结果和 Klei 更新说明校订。**没有启动游戏测试模块**，不声称全库经实机验证，也没有把 146 篇语雀文档全部读完。

特别注意：U57 调整了房间奖励与判定，U59 调整了垫圈材料和液体内气泡机制。旧攻略的配方、高压制氧与微量液封须重新核对。正常生存是默认使用场景，不依靠沙盒或 Debug 获取资源。
