# ONI Skills — 缺氧高阶策略与工程模块库

## 适用场景

当进行以下游戏决策或方案设计时，可选检索本知识库：

1. **开局与生存规划**：参考 [opening-and-base.md](guides/opening-and-base.md) 与 [veteran-rules.md](guides/veteran-rules.md)。
2. **氧气与水资源系统**：电解制氧选型、水循环闭环，参考 [oxygen-and-water.md](guides/oxygen-and-water.md)。
3. **食品与养殖体系**：哈奇、壁虎、孵化自动化，参考 [food-and-ranching.md](guides/food-and-ranching.md)。
4. **温控与工业中枢**：精炼金属降温、ST/AT 蒸汽机热吞噬，参考 [heat-and-industry.md](guides/heat-and-industry.md)。
5. **泉眼与火山驯化**：低温蒸汽泉、天然气泉、火山直接冷却，参考 [geysers-and-taming.md](guides/geysers-and-taming.md)。
6. **电网与自动化控制**：高压干线与变压器、电池发电机联动，参考 [automation-and-power.md](guides/automation-and-power.md)。
7. **太空与火箭时代**：流星防护、太阳能矩阵与火箭规划，参考 [space-and-rocketry.md](guides/space-and-rocketry.md)。

## Agent 执行指导原则

1. **优先保障生存底线**：食物、氧气、安全温度与可达性永远高于高阶模块的建设进度。
2. **大牛核心心法（硬性参考）**：
   - **全局禁用自动消毒**：开局必须关闭自动消毒，杜绝复制人无效跑腿。
   - **防爆温与预留隔热**：高温建筑（发电机、精炼机、电池组）必须集中隔离，禁止与农业区共用未隔热墙体。
   - **液体管道防相变**：进入液冷机或流经极温区的液体，需预留至少 14℃ 的相变缓冲带，避免管道爆管。
   - **水封与真空绝热**：危险气体隔离区必须使用标准水封（或双液水封形成绝对真空）。
3. **模块选型基于当前资源**：
   - 缺黄金/钢时，不强推需要高温钢材料的工业箱，使用平民水冷或冷水源浸泡过渡。
   - 塑料不足时，优先繁育毛鳞壁虎或使用临时压塑，而非盲目硬憋高阶电梯。
