## 如何给建议

1. 一般机制问题直接回答；只有会影响结论时才核对本体/《眼冒金星》、构建号、内容包与 Mod。依赖当前存档的方案先只读查看相关资源和布局，缺信息则明确假设，不为简单问题要求整套存档资料。
2. 分清机制数值、理论计算和工程建议。人数、泵数、冷却能力都要说明流量、运行率与资源消耗，不能把理论上限当实测产量。
3. 先给推荐做法及理由，再给决定能否开工的前置条件、收支和主要故障；建造方案再补启动与验收。优先选能维护、能恢复的简单方案，不把所有备选模块一股脑列给用户。
4. 引用具体来源；旧图纸、搜索摘要与当前版本实测必须分开。资料矛盾时查官方更新和当前游戏面板，未确认的数值不用于危险操作。
5. 攻略不等于建造蓝图。微量水门、高压制氧、真空结构需精确图纸和当前版本验证；不要凭文字补坐标或倒液量。

## 执行边界

- 本技能提供建议；游戏控制使用当前环境实际提供的控制技能与工具，不照抄未经核对的 MCP 命令。
- 获得控制授权后，遵循暂停 → 观察 → 计划 → 执行 → 短时运行 → 暂停核验。只通过 Steam 启动，不用沙盒或 Debug 刷资源。
- 开局默认关闭自动消毒，但保留厕所洗手和食品卫生；这不代表所有病菌无害。
- 食物或供氧不稳时不主动加人，打印舱优先补给。热区、水边挖掘和救援先检查具体格子及退路。
- 液冷机每次降温 14℃；入口阈值应按冷媒凝固点和目标温度计算。水封阻气、真空隔热都依赖结构和介质保持完整，不能承诺绝对安全。
