# 贡献与共同完善指南

`oni-skills` 是一个开放式的知识库，欢迎各位缺氧玩家、Mod 开发者与 AI 工程师共同维护！

## 为什么需要共同完善？

《缺氧》是一个系统极其繁复、更新频繁的物理模拟游戏。
* **机制变化**：官方版本迭代可能改变动植物代谢速率、小动物生蛋率、建筑过载判定等。
* **DLC 差异**：原版（Vanilla）与《眼冒金星》（Spaced Out!）在星系结构、辐射系统、火箭推进和科技树上有显著不同。
* **实战验证**：理论设计在长期运行（1000+ 周期）中可能遭遇管道卡死、过温损坏、病菌堆积等偶发边缘案例。

## 提交准则

1. **结构清晰**：
   * **适用阶段**：开局、中期、中后期还是大后期。
   * **前置条件与材料需求**：如需要精炼金属（铁/铜/金）、钢、塑料、陶瓷还是超冷剂。
   * **核心原理解释**：说明热量转移途径、流体/气体流动规则、自动化信号逻辑。
   * **避坑防翻车要点**：指出最容易因操作不当导致故障的点（如管道破裂、漏气、过热）。
2. **拒绝作弊数据**：
   * 禁止在测试中依靠沙盒工具随意刷超冷剂、真空破坏器等非生存模式正常获取物品。
   * 所有攻略必须在标准生存难度（Survival）下可完全复现。
3. **格式规范**：
   * 采用标准 GitHub Flavored Markdown。
   * 图纸/坐标说明尽量清晰，避免模糊不清的“放在旁边就行”。
