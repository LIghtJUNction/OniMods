# 阶段判断：按依赖而不是按周期

这是本项目的规划顺序；原作者的模块资料用于选型，不把大型成品基地当成开局教程。

| 当前状态 | 当前目标 | 升级前必须看到的证据 |
| --- | --- | --- |
| 开局或有生存警报 | 呼吸、食物、厕所、床与安全通道 | 复制人能到达设施，补给可持续，不存在被困/窒息目标 |
| 基础设施可用，库存持续下降 | 查清水/藻/土/燃料收支，建立可维护的补给 | 实际产出抵得过消耗；生产停机时仍有缓冲 |
| 供氧和食物稳定，温度上升 | 冷却、支路供电、精炼材料、气压服和维护路径 | 启动材料、冷却回路、可靠电源和出口都齐备 |
| 基地可持续，准备资源开发 | 分析泉/火山、工业链与自动化 | 完整喷发/休眠数据、峰值热量和产物去向已核对 |
| 原星可自持，准备太空 | 舱内保障、目的地补给、返航和运输闭环 | 已检查 DLC/难度、氧气、食物或仿生耗材、士气、落地方案 |

任何阶段有新生存警报，先解决直接风险；已有授权的小规模救援不因“大工程正在施工”而延后。

## 三个预算

- 食物缓冲周期 = 可食用且可到达的库存千卡 / 当前需要食物者的总千卡每周期。另算收获、加工、腐败、运输时间。仿生人单列电池/润滑油等消耗。
- 物资续航 = 可用库存 / 净消耗率；净消耗不为正时解释平衡，不输出无意义的负数或除零结果。水要同时承担制氧、种植、研究等需求。
- 电池缓冲时间 = 可用焦耳 / 净功率缺口瓦。库存电量能缓冲停电，不能证明发电长期够用。

速率来自当前难度、角色和运行状态。图纸额定产量要扣除缺水、缺料、停机、工作时长和启动等待。泉的全周期平均供应与喷发峰值要分别算。

研究只排解锁下一项实际可建方案的前置；不要把待研究、待炼钢、待运输的模块排成已可施工。基建验证要看实际库存/温度/压力趋势，不能仅看“蓝图放置成功”。
